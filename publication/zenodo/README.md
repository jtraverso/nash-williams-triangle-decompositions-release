# Zenodo document deposits

Both first editions were published on 20 October 2026 as **preprint 1.0**:

- [Paper I — 10.5281/zenodo.23428173](https://doi.org/10.5281/zenodo.23428173).
- [Paper II — 10.5281/zenodo.23502224](https://doi.org/10.5281/zenodo.23502224).

Each deposit contains four individual PDFs: the article and formalization companion, each in English and Spanish. Public downloads were checked against the SHA-256 hashes of the audited documents. The published receipts record file names, sizes, hashes, metadata and the immutable GitHub source commit. Reservation receipts are retained as historical records; they do not describe the current publication state.

Source archives, scripts and audit evidence remain on the public GitHub repository with pinned source references. No repository clone, cache, build products or historical duplicate packages were uploaded to Zenodo. Documents use CC BY 4.0; source and packaging notices retain Apache-2.0 and their dependency licences.
