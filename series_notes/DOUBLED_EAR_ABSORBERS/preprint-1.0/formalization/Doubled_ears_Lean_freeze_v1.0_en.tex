\textbf{Scope.} The formal lower bound counts the edges of \(A\) whose two endpoints are centres. These are exactly \(A\cap C\) under the induced-host assumption. The equality theorem assumes that \(P\) consists of centre--ear edges in the host, all host edges of that type belong to \(P\), all centre--centre edges belong to \(C\), there are no ear--ear edges, and \(|P|=4|C|\). Its conclusion characterizes equality by two mixed triangle packings of the specified role types with the same non-source edge set. The lemma \texttt{spoke\_mem\_iff} identifies the corresponding auxiliary neighbours at each centre. Section 2 derives the local permutations from these incidences for doubled ears. The transfer theorem additionally takes a mixed-decomposable return set disjoint from the host. For the family in Section 4, Lean checks the six-edge core, its optimum and its obstruction. The argument for arbitrary \(k\) is the gluing and counting proof in that section.

\clearpage\subsection{2. Reproducing the verification}\label{reproducing-the-verification}

The \href{https://github.com/jtraverso/typed-triangle-absorption/tree/c7bae66dfd66370138d2f1a6ecc51d3aa29ea8e4}{source commit} fixes Lean 4.35.0-rc3 and Mathlib revision \nolinkurl{c55e6e786f49471c72fbddbec5415808896aec1e}. The \href{https://github.com/jtraverso/nash-williams-triangle-decompositions-release/releases/download/doubled-ears-preprint-1.0-r2/Doubled_ears_LEAN_SOURCE_v1.0.zip}{source ZIP} contains all 1,588 tracked files, including 1,522 Lean source files and the dependency manifest. Lake obtains the external packages at the revisions recorded in that manifest.

After unpacking the archive, run the following commands from the directory containing \texttt{lean-toolchain}. The first command builds the statement and proof modules for this note. The second runs Comparator on a Linux installation with sandbox and Nanoda support.

\begin{verbatim}
lake build +DoubledEarsChallenge +DoubledEarsSolution
lake comparator --config comparator.doubled-ears.json
\end{verbatim}

The challenge uses one \texttt{sorry} for each of the eight proposed statements. The solution imports the proofs through \texttt{DoubledEarsSolution}. Querying each declaration from that module reports exactly \texttt{propext}, \texttt{Classical.choice} and \texttt{Quot.sound}. On Windows the comparison used Lean's default kernel with the sandbox and Nanoda disabled. The \href{https://github.com/jtraverso/nash-williams-triangle-decompositions-release/tree/doubled-ears-preprint-1.0-r2/series_notes/DOUBLED_EAR_ABSORBERS/preprint-1.0/formalization}{verification record} gives the configuration and the output for all eight declarations.
